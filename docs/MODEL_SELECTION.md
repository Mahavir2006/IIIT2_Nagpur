# Model selection and status

Updated 26 October 2026.

## Current implementation

- **Weather:** PRAVAAH consumes Open-Meteo's provider-selected `best_match` hourly forecast for one Marine Lines coordinate. This is an external weather forecast. PRAVAAH does not train, fine-tune, or claim its own weather model.
- **Measured models:** persistence, 7-day seasonal-naïve, and horizon-specific ridge regression were evaluated on a 2025 chronological holdout against ERA5 hourly reanalysis for 1, 6, 24 and 72-hour precipitation sums. Ridge uses past rainfall windows and local hour/year cyclic terms, standardized on training-period samples; target sums remain strictly after each prediction origin. It beats both naïve baselines on 6/24/72-hour MAE and RMSE. At 1 hour, persistence has slightly lower MAE (0.096 vs ridge 0.101 mm), while ridge has lower RMSE (0.313 vs 0.321 mm). Results and dataset hash are in `data/evaluation/rainfall-baseline-2025.json` and `/evaluation`; all scores are agreement with reanalysis, not independent forecast skill or rain-gauge validation.
- **Pretrained-model candidate:** Amazon Chronos-2 remains unbenchmarked. The local Python environment has PyTorch and Transformers but does not have the `chronos` package or cached `amazon/chronos-2` checkpoint. The official [Chronos repository](https://github.com/amazon-science/chronos-forecasting) and [checkpoint page](https://huggingface.co/amazon/chronos-2) document the candidate and its Apache 2.0 license. Do not claim a benchmark until the checkpoint is actually run on the same chronological split and compared against these baselines. The current 120M candidate and its inference dependencies/latency have not been downloaded or measured.
- **Urban impacts:** the bundled deterministic engine transforms a user-controlled synthetic rainfall scenario into drainage, road, facility and response outputs. These are scenario calculations, not forecasts of real flood impacts.
- **Synthetic multi-system impact surrogate:** `scripts/train_synthetic_flood_model.py` trains River SGD regression/classification using features covering rainfall, river/soil, traffic/transit, power, hospital/EMS, satellite/geospatial, historical incidents, and citizen reports. The `/api/pravaah/india/predictions` inference route uses live Open-Meteo rainfall plus deterministic simulated proxies for system feeds that are not connected, and returns feature values and domain provenance. Drainage/urban/coastal context comes from static registry proxies. Holdout metrics in `data/evaluation/synthetic-cascade-model-v2.json` are agreement with the same synthetic teaching rule, not empirical impact skill, calibrated probabilities, or all-India warning performance. Research-only. Regenerate with `npm run train:synthetic-flood-model`; validate with `npm run verify:synthetic-flood-model`.
- **Cascade demo:** `/api/pravaah/cascade` event-time replays 48 hours of deterministic synthetic multi-system signals. It discovers positive lagged associations from same-zone hourly streams, keeps low-strength physical priors explicitly separate, and computes a reproducible Monte Carlo horizon distribution and time-to-critical quantiles. This exercises pipeline mechanics only; the inferred graph and probabilities are synthetic, not causal or operational evidence.
- **Routes:** OSRM supplies road-network geometry and nominal estimated duration when the provider responds. It does not provide live traffic. TomTom is an optional provider path.
- **Online candidate:** River 0.26.1 (BSD-3-Clause) is used by `scripts/evaluate_online_rainfall.py` for an online SGD rainfall regressor and heavy-rain event classifier. On the same 2025 Marine Lines ERA5 feature replay it is better than the last-hour baseline at 6h and 24h MAE, but worse at 1h and 72h; it does not outperform the existing ridge results at the longer horizons. The event classifier misses most positive 24-hour rainfall cases. The measured report is `data/evaluation/river-online-rainfall-2025.json` and is published to `/data/river-online-rainfall-2025.json`. It is a research/evaluation candidate, not an active warning model or the Node/Vercel runtime model.
- **Online quality controls:** the River replay uses event-time delayed label release, a future-label guard, basic schema/range screening without discarding valid extremes, ADWIN residual/error drift signals, capped SGD learning-rate increases, prequential calibration and rolling conformal residual intervals. Empirical holdout interval coverage is below the nominal 90%, so these intervals are not presented as guaranteed coverage.

## Not selected or claimed

No pretrained Chronos/TimesFM model or calibrated hydrodynamic flood model has been evaluated or deployed. The River synthetic surrogate is a reproducible software/modeling baseline, not a substitute for observed flood labels. There is no verified historical flood outcome corpus, gauge-linked training set, flood-depth raster, traffic/transit telemetry, power status feed, or hospital/EMS feed wired to the India-level model. Do not use the synthetic endpoint as an operational warning.

River's 2025 event metrics are not flood-risk metrics: the positive label is a fixed 24-hour rainfall amount threshold over ERA5 reanalysis, and the measured false-negative rate is high. Neither the River model nor the synthetic all-state scores should be used for operational warnings. Risk-model evaluation remains blocked on verified, location-linked impact labels and independent observations.

## Future selection gate

Before selecting a locally trained forecast model, assemble timestamped gauge/radar/weather inputs with reliable source and issue times, spatial coverage, and independently verified flood/road impact labels. Establish persistence and climatology baselines; split by time and event (not random rows); compare calibration and lead-time performance; document missingness, operational latency, and geographic transfer limits. A more complex model must outperform the baselines on held-out events and have an explicit failure/fallback policy.
